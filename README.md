# Smart Motorcycle Parking Dashboard (Zone B1)

ระบบตรวจจับและนับที่ว่างรถจักรยานยนต์อัตโนมัติ อาคารเรียนรวม 1 มทส. พัฒนาด้วย YOLO11 และ Streamlit

## วิธีการติดตั้งและรันระบบ
1. ติดตั้งแพ็กเกจที่จำเป็น:
   pip install -r requirements.txt

2. รันแอปพลิเคชัน:
   streamlit run app.py
